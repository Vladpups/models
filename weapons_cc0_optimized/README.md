# Оружие, CC0, оптимизировано до 10 000 полигонов

34 модели из пака `Ravi-Rutgers/airsoft-3d-model-pack` (GitHub, публичный). Все файлы прошли оптимизацию glTF Transform (дедупликация, очистка неиспользуемых данных) без квантования и без упрощения геометрии. Треугольники и габариты совпадают с исходниками. Все файлы проходят валидатор Khronos без ошибок. Для `shotgun-pump-east.glb` отключена flatten, иначе валидатор ругался на скин.

Важно: модели НЕ реалистичные. В манифесте пака все они помечены как `generic_comparable` и названы "Stylized". Текстур нет, материалы однотонные. Реалистичных CC0 моделей оружия из этой среды скачать не удалось.

Файлы из архива пользователя (M433, B36A4, M4A1) в этой папке не используются.
